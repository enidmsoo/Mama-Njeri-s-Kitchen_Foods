FRESH KENYAN FOOD WEBSITE
=========================

FILES
-----
index.html          Main website page.
style.css           External CSS stylesheet (main design).
script.js           Small JavaScript interaction for the order form.
internal-style.html Separate example showing internal CSS.
images/food1.jpg    First gallery image, cropped from your reference screenshot.
images/food2.jpg    Second gallery image, cropped from your reference screenshot.
images/food3.jpg    Third gallery image, cropped from your reference screenshot.

HOW TO OPEN
-----------
1. Extract the ZIP folder.
2. Open the Kenyan_Food_Website folder.
3. Double-click index.html. It should open in your web browser.
4. To edit the website, open the folder in Visual Studio Code or another text editor.
5. Keep index.html, style.css, script.js, and the images folder together.

CSS TYPES INCLUDED
------------------
- External CSS: style.css, connected using the link element in index.html.
- Internal CSS: a small style element in index.html, plus a separate
  internal-style.html demonstration page.
- Inline CSS: not needed for this design; the main styles are kept in style.css.

NOTE
----
The order form is a front-end demonstration only. It displays a confirmation
in the browser and does not send orders to a restaurant or save them in a database.
